# Dictionnaire IT — Référentiel vivant

Base de connaissances structurée pour un dictionnaire de commandes informatiques.
Organisé en deux faces :

- **Face A** : commandes indexées par système (Linux / Windows / macOS) et par catégorie.
- **Face B** : index des abréviations et acronymes du monde informatique.

Chaque entrée de commande contient :
`commande | OS | rôle | syntaxe | exemples | précautions | équivalents`

Ce référentiel est destiné à être importé dans une base de données (JSON / SQLite / Firestore).
